# Country flags

The 265 two-letter (ISO 3166-1 alpha-2) flags from [circle-flags](https://github.com/HatScripts/circle-flags) by HatScripts, version 2.8.3, copied unmodified from the npm package's `flags/` folder (its regional, language and alias files are left out) and used under the MIT licence in `LICENSE` beside this file. `SugarCommerce\Geo\Flags` is the only thing that reads them; to update, replace the `xx.svg` files with those of a newer release and change the version here.
